# 15 类前景 Case 池统计：MTARSI、MAR20 与合并

统计日期：2026-09-23  
适用分类：C-17、C-130、KC-135、KC-10、A-10、F-15、F-16、F/A-18、F-12/YF-12A、F-35、B-1B、B-52H、E-2、E-3、直升机。

## 统计单位与边界

- **MTARSI**：一张类别 crop 记为一个可抠图的原始前景 case。因此其数量是“可进入抠图 pipeline 的原始输入数”，不是质量门通过数。
- **MAR20**：一个 OBB 标注实例记为一个**待裁切/待分割** case。MAR20 是遥感场景图；其数字不代表已经获得透明前景 PNG，同一图可含多个实例。
- **合并池**：MTARSI crop 数与 MAR20 OBB 实例数的算术和，仅用于估算候选规模；两者的成像方式、裁切方式和质量门不能混为同一数据分布。
- 严格遵守型号映射：`C-135` 不计入 KC-135，`KC-767` 不计入 KC-10；F-12/YF-12A 与直升机在两来源中均未找到。

## 采样建议

1. 把 **E-2（109）**、**F-35（239）**、**KC-10（308）** 标记为低样本类；F-12/YF-12A 与直升机为零样本类，不能通过过采样解决。
2. F/A-18 的 MAR20 OBB 候选有 2,632 个，而 MTARSI 只有 72 个。合并训练前必须设置每类生成上限或目标配额，否则 F/A-18 会被过度放大。
3. MAR20 前景要走一条独立流程：`OBB -> 带 padding 的局部 crop -> SAM2 前景分割 -> 自动质量门 -> 透明 PNG`。在该流程完成前，13,085 只是候选量，不应写成“已通过的透明前景数量”。
