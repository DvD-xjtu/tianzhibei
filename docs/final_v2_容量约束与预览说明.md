## 输入与数量

- 背景仍为六个 LAE 训练子集；FAIR1M 排除 `valid_` 图片，只接受原图具有飞机 GT 的场景。
- 使用补全后的 `crop-metadata/training_pool_no_exact_heldout_overlap.jsonl`，共 5,739 条；仅 fixed、innar_train、mar20_train。继续做原有 paste 源质量预检后，4,794 条可参与本轮。
- 不直接 glob `crop-image`，不使用 held-out 前景。精确去重不代表已经排除所有同场景近似重复。
- 新生成 1,000 张目标：DIOR、DOTAv2、FAIR1M、NWPU 各 167 张，RSOD、xView 各 166 张。
- 类别按成功实例数量做软平衡；不同原始 crop 优先，允许一图内混合类别；同一图内原始 crop ID 不重复。本批不承诺各类等量。

## 先估计容量，再随机取数

1. 读取原图所有 GT 作为禁入区，飞机 GT 另外用于拟合尺度和定位候选地面。
2. 使用训练池实际旋转后形状建立模板，采用与正式粘贴一致的尺寸、面积、地面质量及避碰规则，进行最多三轮贪心试排布，每轮最多排六架。
3. 取最佳试排布得到的数量作为保守可行容量 C，最多六架。它是试排布找到的可行数量，不是数学意义的最大容量，也不保证每个随机 crop 都能通过外观质量门。
4. C=0 换背景；C>0 时从 1…C 均匀抽请求数。不是先在 1…6 中盲抽。
5. 每个请求槽位最多尝试 24 次，每次可换 crop、角度、尺寸和位置；每成功一架，立即更新占用区域。不会复用旧版的位置缓存。
6. 空间或质量不满足时少贴；零通过实例的背景尝试不输出。所有图片满足 `1 ≤ 实际数 ≤ 请求数 ≤ 估计容量 ≤ 6`。
7. 每子集最多尝试目标图片数的 40 倍，达到预算未完成就报错，避免无限重试。

因此最终 1–6 架的直方图通常不均匀，质量门和空位会使分布偏向较小数量。manifest 记录容量、试排布框、请求数、实际数及缺额。

## 尺度采样

- 定义线性尺度 `s = sqrt(HBB 宽 × HBB 高)`，单位像素。只使用原图飞机 GT，排除其他目标；新增实例不参与重新拟合。
- 原图至少十架时先去掉尺度两端各 10% 的极端值；其余情况保留全部尺度；均值来自当前图。
- 拟合样本不少于五个时使用本图变异系数，否则借用同背景子集训练飞机的变异系数。变异系数限制在 0.08–0.35，使同尺度场景仍有轻微变化，避免极端方差。
- 正态分布的截断下限为 `max(16 px, 0.6×局部均值, 子集归一尺度P05×sqrt(图面积))`；上限为 `min(1.6×局部均值, 子集归一尺度P95×sqrt(图面积), 图短边/3)`。
- 用拒绝采样实现截断正态，最多 64 次；不把越界抽样值硬截到端点。区间为空就跳过背景。
- 保持前景长宽比，按旋转后 mask 的 HBB 计算缩放比例。缩放不超过 2 倍；栅格化后重新检查实际 HBB 尺度仍在截断区间。
- 实际 HBB 短边至少 16 px，硬 mask 至少 100 像素；含羽化留白的前景贴片长边不超过背景短边的 1/3；本图所有新增 HBB 面积之和不超过图面积的 20%。

这拟合的是图内可见飞机的像素尺度，未加入机型真实翼展/GSD。大型客机背景上粘贴战斗机可能仍有物理比例偏差；HBB 尺度也随朝向变化。本轮是供视觉判断的实验，不预先认定正态分布优于 v1。

## 位置、明暗与质量门

- 在原有飞机邻域生成候选位置，保持原有地面颜色、纹理、植被和边缘阈值。
- 贴片离图边至少 8 px，与原有全部 GT 及此前新增贴片保持至少 8 px 间隔；使用完整贴片避碰，保护羽化区域。
- 旋转 0–360°，预乘 alpha 重采样；沿用 Lab 上下文匹配和锐度适应。
- 颜色匹配之后额外调整 Lab L：乘以 0.90–1.10，再加 −3…+3（L 的范围 0…100）。不改 mask。新引入的亮度裁切比例超过 2% 就拒绝这次尝试。
- 羽化 sigma 为 0.50–0.80。每个新增实例记录具体明暗参数、缩放、角度、位置、crop 来源和指标。
- 延续 `engineering-v7-1` 质量门，不放宽阈值。既有亮度门更容易保留较暗飞机，最终亮度参数分布可能偏离原始均匀抽样分布。
- 合成结束后，对实际 JPEG 解码像素逐实例重算质量指标；失败的实例移除，重新编码并再次检查，直到所有保留实例通过。
- 颜色/纹理规则不是地面语义分割，颜色相近的屋顶或道路可能仍被误选。展板供用户检查该问题。

## 输出及验收

- 每图一个 YOLO HBB 标签文件：先写所有新增实例，再保留原图全部类别标注（`LAE/原类名`）。
- 每图一个实例 ID PNG：0 为背景，1…N 为新增飞机，与 manifest 一一对应。
- 各子集独立 manifest 和 progress；根目录 config、冻结前景清单、源预检拒绝清单、代码快照；各子集另存背景清单来源哈希、合格背景 ID 和随机种子。
- 独立检查哈希、mask 与框一致、数量链式约束、原标注保留、类别映射、原始 crop 不重复、边界、碰撞、面积与尺寸，以及最终 JPEG 明暗质量门。
- 预览展板位于“final产出”下的 v2 条目，按实际新增 1–6 架筛选，只显示新增飞机的框；完整训练格式标签不受展示影响。
- 工程检查通过不表示通过逐张语义/视觉审核；本轮保持 `preview_pending_review`。
