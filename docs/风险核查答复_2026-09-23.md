# Copy-Paste 风险核查答复

更新日期：2026-09-23。以下是 pipeline 编写前的简明实测答复。

## 风险 1：前景 mask

- **MTARSI-fixed**：实际可读 984 图；宽/高的 min/P50/P95/max 分别为 `80/161/312/416`、`80/161/297/424` px，最常见尺寸为 128×128（88 图）和 160×160（28 图）。
- **MTARSI-INNAR**：实际可读 9,835 图；宽/高 min/P50/P95/max 为 `80/215/344/588`、`80/203/329/600` px，常见 128×128、160×160、256×256，且存在非方形裁剪。
- **随机 20 图目检**：均为以单架飞机为主体的遥感裁剪图；均带真实停机坪/跑道/地表背景，多个样本有明显阴影，未见纯色或天空背景。未做全量 mask 统计，因此不能声称 mask 失败率；必须先做 smoke test 后以通过率决定是否全量。
- **现有依赖**：`lae-dino` 与 `tianzhibei-mmrotate` 环境均有 PyTorch/torchvision；未安装可 import 的 SAM、SAM2、GroundingDINO。

## 风险 3：LAE-1M 背景

- `manifests/background_train.jsonl` **当前不存在**，因此总量与六来源比例尚未冻结；外部 AI 不可自行把候选目录全量用作背景。
- 当前候选图像库存：DIOR 11,725；DOTAv2 17,480；FAIR1M 64,147；NWPU 650；RSOD 976；xView 21,100。
- 六来源图像尺寸分布尚未统计，因为允许背景清单未冻结；应只针对最终清单统计，避免得到与实际合成无关的分布。
- 候选标签中的飞机框数：DIOR 717，DOTAv2 7,469，FAIR1M 25,250，NWPU 226，RSOD 2,149，xView 281（Small Aircraft + Cargo Plane）。这些只是候选池统计，不能替代训练清单。

## 风险 4：尺度

MAR20 train 可统计，且已统计。目标映射类的平均 OBB 长边 / 平均面积 / 面积中位占图比例为：C-130 `123.4 px / 13,113 / 1.65%`，C-17 `133.4 / 17,369 / 2.17%`，C-5 `174.8 / 29,689 / 3.63%`，F-16 `118.4 / 10,803 / 1.44%`，E-3 `124.8 / 15,242 / 1.62%`，B-52 `156.0 / 23,353 / 3.43%`，B-1B `114.3 / 12,997 / 1.66%`，F-15 `142.8 / 15,065 / 1.97%`，F/A-18 `101.3 / 7,929 / 1.12%`。

候选 LAE 背景飞机框面积占图比例 P5/P50/P95：DIOR `0.034/2.855/14.168%`，DOTAv2 `0.043/0.486/6.246%`，FAIR1M `0.331/1.156/3.867%`，NWPU `0.318/0.758/1.944%`，RSOD `0.050/0.282/1.076%`，xView `0.067/0.107/0.342%`。首轮缩放不能只照 MAR20；应按最终选中背景子集的分布采样。

## 风险 5：标签策略

- `configs/class_mapping.yaml` **尚不存在**。
- 建议首轮冻结为 **MAR20-20 类主任务**，但实际可从 MTARSI 准确迁入 MAR20 标签空间的类别为 9 类：C-130、C-17、C-5、F-16、E-3、B-52、B-1B、F-15、F/A-18。
- KC-135、KC-10 不能由 C-135 或 KC-767 冒充；A-10、E-2、F-35 需进入扩展 taxonomy 后才能使用。

## 风险 6：额外模型与硬件

- Hugging Face 公网探测成功，技术上可下载权重；应由项目负责人锁定具体权重、许可证与版本后再下载。
- 共 8 张 Tesla V100S 32 GB。当前每张尚有约 23.3–29.0 GB 空闲显存。
- `lae-dino`：Python 3.8.20、PyTorch 1.13.0+cu116；`tianzhibei-mmrotate`：Python 3.8.20、PyTorch 2.0.1+cu118；系统 `nvcc` 为 10.1。
- SAM/SAM2/GroundingDINO 均未安装；torchvision 已有。可装 SAM 系列，但先以小样本测显存、速度与 mask 通过率。

## 风险 7：生成规模

规模尚未由负责人冻结。建议：第一步仅生成不超过 100 张 smoke-test 图；mask 和粘贴人工检查通过后，再做 2,000–5,000 张首轮训练增强集。不要以“接近 MAR20 train 的 1,331 图”为目标；应由每类实例上限、背景可用数量和训练消融结果决定。

## 临时背景统计（供 scale_sampler / placement_sampler 设计）

这是候选库全量标签统计；尚不是 `background_train.jsonl` 的最终训练分布。面积为飞机 HBB 面积除图像面积，依次给出 P5/P50/P95；xView 只计 Small Aircraft 与 Cargo Plane，FAIR1M 只计其 11 个飞机型号及 other airplane。

|---|---|---:|---|
| DIOR | 11,725；800×800（全量） | 717 | 0.034% / 2.855% / 14.168% |
