# Copy-Paste v8：前景增强与 500 例粘贴实验

## 前景变体生成

输入为 MTARSI-fixed 与 MTARSI-INNAR **Train** 中已通过现有抠图工程门的 cutout；只使用本轮 8 个可映射类别，不引入 INNAR valid/test。每个基础前景生成 4 个变体：0–360°旋转、0.8–1.2 倍缩放，以及很轻的亮度（±3）、对比度（0.97–1.03）和像素噪声（标准差不超过 1.2）扰动。RGB 和 alpha mask 使用同一仿射变换；几何门检查主体连通性、碎片比例和 mask 面积。

基础前景 **2,045 个**，计划生成 8,180 个变体；实际变换后通过 **8,177 个**，拒绝 3 个（mask 几何异常）。这是 2,045 个飞机 cutout 的派生增强视图，不代表 8,177 架独立飞机。按类通过数：

| 类别 | 基础 cutout | 增强变体通过 |
| --- | ---: | ---: |
| C-130 | 384 | 1,535 |
| C-17 | 318 | 1,272 |
| F-16 | 93 | 371 |
| E-3 | 302 | 1,208 |
| B-52 | 496 | 1,984 |
| B-1B | 351 | 1,404 |
| F-15 | 61 | 243 |
| F/A-18 | 40 | 160 |

派生 cutout 与逐例变换参数保存在 `/data3/tianzhibei/derived/lae1m_mtarsi_copypaste_v1/foreground_aug_v1_8class/`；`manifest.jsonl` 记录基础 ID、来源、增强参数、mask 几何统计与文件校验值。

## 500 张 MAR20 粘贴实验

使用上面的增强前景池，在 MAR20 train 背景上均衡生成 8 类；原 MAR20 OBB 保留，并附加合成飞机 OBB。500/500 候选结构审计通过，错误 0。固定工程过滤器放行 **138/500（27.6%）**，拒绝 362 张。过滤不读取人工审阅信息，本批未由助手视觉检查。

| 类别 | 候选 | 工程通过 | 通过率 |
| --- | ---: | ---: | ---: |
| C-130 | 63 | 17 | 27.0% |
| C-17 | 63 | 24 | 38.1% |
| F-16 | 63 | 26 | 41.3% |
| E-3 | 63 | 10 | 15.9% |
| B-52 | 62 | 13 | 21.0% |
| B-1B | 62 | 25 | 40.3% |
| F-15 | 62 | 17 | 27.4% |
| F/A-18 | 62 | 6 | 9.7% |

按第一条触发规则统计 362 个拒绝样本（单例可能同时触发多条）：

| 首要拒绝原因 | 数量 |
| --- | ---: |
| 粘贴位置纹理过强 | 128 |
| 飞机与背景对比不足 | 59 |
| 粘贴亮度不匹配 | 49 |
| 植被过多 | 35 |
| mask 碎片 | 32 |
| 源前景疑似带入背景 | 25 |
| 位置边缘过密 | 19 |
| 位置颜色不匹配 | 8 |
| 灰度背景上的彩色前景 | 6 |
| 饱和度不匹配 | 1 |

与 v7 的 200 张原始前景候选相比，工程通过率为 27.6% 对 28.0%，整体相近。该比例衡量的是这套固定规则的放行率，不是人工可用率，也没有证明扰动提升识别效果。类别数量有差异，尤其 F/A-18 工程通过 6/62；训练前仍需按目标类别映射和分布策略处理。
